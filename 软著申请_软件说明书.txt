一、软件概述

1.1 软件基本信息

软件类型：应用软件（Web 应用，B/S 架构）

1.2 软件用途

本软件面向二手商品交易场景，为个人卖家与商家提供一站式智能发布与估价辅助服务。用户上传商品照片后，软件自动完成商品识别、瑕疵检测、市场行情查询与带货文案生成，帮助用户快速完成二手商品的定价与上架发布，显著降低二手交易的信息整理成本。

1.3 主要功能

（1）商品智能识别：基于 YOLOv8 目标检测模型与 Qwen-VL 视觉大模型，自动识别上传照片中的商品品类、品牌、型号与成色。
（2）瑕疵损伤检测：基于独立训练的 YOLO 瑕疵检测模型，自动标注商品外观瑕疵，并输出成色分级。
（3）二手行情查价：采用"缓存—实时爬虫—AI 推算"三层匹配策略，查询商品市场行情价格区间。
（4）AI 文案生成：基于 DeepSeek 大语言模型，流式生成商品标题、描述与建议售价。
（5）商品商城与搜索：支持商品浏览、多维筛选、以图搜图、以文搜图与语义搜索。
（6）价格历史追踪：生成商品过去 6 个月价格走势曲线，辅助定价决策。
（7）用户与权限管理：支持注册登录、消息通知与后台管理。


二、系统架构

2.1 技术架构

本软件采用前后端分离的 B/S 架构：

（1）后端服务：基于 Python FastAPI 框架构建，提供 RESTful API 接口，负责业务逻辑、AI 模型调用、数据库访问与安全校验。
（2）前端界面：基于 Vue 3 框架构建单页应用（SPA），负责用户交互与数据展示。
（3）数据存储：使用 MySQL 关系型数据库存储用户、商品、发布记录等结构化数据；使用 Qdrant 向量数据库存储商品图像特征向量，支持相似度检索。
（4）AI 模型层：集成 YOLOv8（商品检测与瑕疵检测）、CLIP（图像与文本特征提取）、Qwen-VL-Max（视觉语义识别）、DeepSeek（文案生成、价格估算与语义搜索）。

2.2 功能模块划分

本软件后端由以下功能模块构成，各模块以路由（Router）为单位组织：

（1）用户认证模块（auth）：用户注册、登录、JWT 令牌签发。
（2）商品检测模块（detect）：YOLOv8 商品目标检测。
（3）信息抽取模块（extract）：调用 Qwen-VL 识别商品品类、品牌、型号与成色。
（4）瑕疵检测模块（process / defect）：YOLO 瑕疵检测、成色分级。
（5）行情查询模块（price / price_history）：市场行情查询与历史价格。
（6）文案生成模块（generate）：DeepSeek 流式文案生成。
（7）商城模块（market）：商品发布、浏览、筛选。
（8）搜索模块（search）：以图搜图、以文搜图、语义搜索。
（9）历史模块（history）：发布历史记录管理。
（10）通知模块（notifications）：站内消息通知。
（11）后台管理模块（admin）：用户管理、数据统计、模型训练调度。

三、功能模块说明

3.1 用户注册与登录

功能说明：
本软件提供用户注册与登录功能。新用户通过用户名与密码注册普通用户账号；登录成功后，后端签发 JWT（JSON Web Token）访问令牌，用于后续接口的身份校验与权限控制。

操作步骤：
（1）打开软件进入登录页面。
（2）未注册用户点击"注册"，输入用户名（不少于 2 个字符）与密码（不少于 6 位）。
（3）注册成功后返回登录页，输入用户名与密码登录。
（4）登录成功后进入首页，顶部导航栏显示用户名与各功能入口。

实现对应：
该功能由后端 auth 模块的注册与登录接口实现，令牌签发由 jwt_handler 模块的 create_access_token 函数完成；前端对应 LoginPage.vue 与 RegisterPage.vue 页面。

3.2 商品智能识别

功能说明：
用户上传商品照片后，软件首先调用 YOLOv8 目标检测模型识别图片中的物品目标，随后调用 Qwen-VL 视觉大模型对商品进行语义级识别，输出商品的品类、品牌、型号与成色判断结果。

操作步骤：
（1）进入发布页，点击上传按钮选择商品照片（支持多张，单张不超过 10MB）。
（2）图片上传后，软件自动执行目标检测与视觉识别。
（3）识别结果以结构化信息展示，包括品类、品牌、型号、成色等级。
（4）用户可对识别结果进行确认或手动修改。

实现对应：
该功能由 detect 模块（YOLOv8 检测）、extract 模块（Qwen-VL 识别）与 ml/yolo_detector.py、llm/qwen_vl_client.py 实现；前端对应 HomePage.vue 页面与 ImageUploader.vue 组件。

3.3 瑕疵损伤检测

功能说明：
软件基于独立训练的 YOLO 瑕疵检测模型，对商品照片进行外观瑕疵检测，可识别七类瑕疵：穿透、变形、功能故障、结构损坏、溢漏、表面瑕疵、部件缺失。系统根据瑕疵类型、面积占比与置信度，将瑕疵划分为重度、中度、轻度、轻微四级严重程度，并综合汇总输出五级成色分级（完整、轻微瑕疵、中度瑕疵、重度瑕疵、完全损坏）。

操作步骤：
（1）上传商品照片后，软件自动执行瑕疵检测。
（2）检测结果以不同颜色与形状的标注框在原图上标记瑕疵位置。
（3）系统输出瑕疵类型、数量与成色分级结果。
（4）成色分级结果作为后续估价与文案生成的重要依据。

实现对应：
该功能由 ml/defect_detector_yolo.py 的 DefectDetector 类实现，其 determine_severity 方法负责严重程度判定，grade_condition 方法负责五级成色分级；前端在发布页展示标注结果。

【此处插入界面截图：瑕疵检测标注结果页】


3.4 二手行情查价

功能说明：
软件采用三层匹配策略查询二手商品市场行情：
（1）第一层：数据库缓存，24 小时内已查询过的同款商品直接命中缓存，毫秒级返回。
（2）第二层：实时爬虫，缓存未命中时通过 OneBound 电商数据接口实时抓取全网最低价、最高价与均价。
（3）第三层：AI 推算，历史数据不足时调用 DeepSeek 推算价格，或回退到数据库已有记录。

操作步骤：
（1）在商品信息确认后，系统自动触发行情查询。
（2）软件返回该商品的市场均价、最低价与最高价区间。
（3）用户可点击"查看历史详情"，进一步查看该商品的历史价格走势。

实现对应：
该功能由 price 模块与 services/price_service.py 的 query_price、query_price_detail 函数实现；爬虫逻辑位于 services/crawler_service.py。

3.5 AI 文案生成

功能说明：
软件基于 DeepSeek 大语言模型，根据已确认的商品品类、品牌、型号、成色与行情价格区间，通过 SSE（Server-Sent Events）流式接口自动生成商品的带货标题、详细描述与建议售价。生成过程逐字返回，用户可实时看到文案生成进度。

操作步骤：
（1）商品识别、瑕疵检测与行情查询完成后，点击"生成文案"。
（2）软件以流式方式逐步输出生成的标题与描述。
（3）生成完成后，用户可编辑文案并确认建议售价。
（4）确认后商品进入发布流程。

实现对应：
该功能由 generate 模块与 services/text_service.py 的 generate_text_stream 函数实现，采用 SSE 流式响应；前端在 HomePage.vue 中通过流式读取接口展示文案。

3.7 以图搜图、以文搜图与语义搜索

功能说明：
（1）以图搜图：用户上传图片后，软件使用 CLIP 模型提取图像特征向量，并在 Qdrant 向量数据库中检索相似商品。
（2）以文搜图：用户输入文字描述，软件提取文本特征向量，检索匹配商品。
（3）语义搜索：软件调用 DeepSeek 对用户自然语言查询进行语义理解，实现模糊匹配（如搜索"风扇"可匹配"电风扇""落地扇"）。

操作步骤：
（1）进入搜索页，选择搜索方式（图片搜索 / 文字搜索 / 语义搜索）。
（2）上传图片或输入描述文字。
（3）软件返回相似商品列表，并展示相似度得分。

实现对应：
该功能由 search 模块实现，特征提取由 ml/clip_extractor.py 完成，向量检索由 ml/qdrant_client.py 完成，语义搜索调用 llm/deepseek_client.py；前端对应 SearchPage.vue 页面。

3.9 价格历史趋势

功能说明：
软件根据商品品牌与型号，生成过去 6 个月的价格走势数据（每 3 天一个数据点，共约 60 个点），并以折线图形式展示。价格数据优先由 DeepSeek 生成，若调用失败则使用内置公式兜底（结合二手数码每月 3%–8% 贬值规律与随机波动，模拟真实价格走势）。

操作步骤：
（1）在行情查询结果中点击"查看历史详情"。
（2）软件展示该商品过去 6 个月的价格走势曲线，包含均价、最低价与最高价。
（3）若包含 AI 推算数据，页面会标注数据来源与推算说明。

实现对应：
该功能由 price_history 模块与 services/history_estimator.py 的 estimate_history 函数实现；前端对应 PriceHistoryPage.vue 页面。

四、软件操作流程

本软件的核心使用流程如下：

（1）用户注册并登录系统。
（2）进入发布页，上传待售商品照片。
（3）软件自动完成商品识别与瑕疵检测，输出品类、品牌、型号、成色与瑕疵标注。
（4）用户确认商品信息，软件自动查询市场行情价格区间。
（5）用户点击生成文案，软件流式生成商品标题、描述与建议售价。
（6）用户确认文案与价格，商品进入发布流程，并同步建立图像检索索引。
（7）其他用户可在商城浏览、筛选、搜索该商品。
（8）用户可随时查看发布历史、价格趋势与消息通知。
